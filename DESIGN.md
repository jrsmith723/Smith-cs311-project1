## HASH MAP
           | A | Node A   | B | Node B
                |              |
                |              |
                |              |
                v              v
## DOUBLY LINKED LIST

| HEAD |<-->| Node A |<-->| Node B |<-->| TAIL |
             value: 10    value: 20

The hash map stores references to nodes, not the values themselves. Each key points to its corresponding node in the doubly linked list.
